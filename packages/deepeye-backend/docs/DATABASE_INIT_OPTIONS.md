# 数据库初始化说明

## 概述

项目使用 SQLAlchemy 的自动建表功能来初始化数据库。这种方式简单直接，适合早期开发和快速迭代。

## 使用方法

### 初始化数据库表

运行初始化脚本：

```bash
# 使用 Python
python scripts/init_db.py

# 或使用 uv
uv run python scripts/init_db.py
```

这个脚本会：
1. 连接到配置的 PostgreSQL 数据库
2. 根据 SQLAlchemy 模型自动创建所有表
3. 如果表已存在，会跳过（不会报错）

### 创建的表

脚本会自动创建以下表：
- `users` - 用户表
- `password_reset_tokens` - 密码重置令牌表
- `workflows` - 工作流表

## 工作原理

`init_db.py` 脚本使用 SQLAlchemy 的 `Base.metadata.create_all()` 方法，它会：
- 读取所有已导入的模型定义
- 自动生成 CREATE TABLE 语句
- 创建表结构（包括索引、外键等）

## 优势

- ✅ **简单直接**：模型即定义，自动创建表
- ✅ **零配置**：不需要维护迁移文件
- ✅ **快速迭代**：修改模型后直接运行脚本即可
- ✅ **降低门槛**：新贡献者更容易上手

## 注意事项

- ⚠️ **无版本控制**：无法追踪历史变更
- ⚠️ **无回滚**：不能回退到之前的版本
- ⚠️ **数据迁移**：需要手动处理数据迁移（如果有）
- ⚠️ **生产环境**：如果生产环境已有数据，需要谨慎使用

## 适用场景

- ✅ 早期开发阶段
- ✅ 数据库结构变化频繁
- ✅ 可以接受重新创建数据库
- ✅ 开源项目，降低贡献门槛

## 未来迁移

如果项目成熟后需要版本控制和迁移管理，可以考虑：
- 引入 Alembic 进行数据库迁移管理
- 或使用云数据库的迁移工具（如 AWS RDS、Google Cloud SQL）
