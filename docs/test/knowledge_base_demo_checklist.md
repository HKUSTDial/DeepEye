# Knowledge Base Demo Checklist

## Purpose

This document is a video-editing-ready mock checklist for the Knowledge Base demo.
It is designed to match the current frontend document table columns exactly:

- `Document`
- `Segment Mode`
- `Words`
- `Recalls`
- `Uploaded`
- `Status`

## Demo Assumptions

- Company context: `Northwind Coffee`, a multi-city retail coffee chain.
- The first knowledge base contains `50` distinct mock files for a dense UI demo.
- Each mock file is assumed to contain roughly `40-50 lines` of content.
- `Segment Mode` is set to `Auto` everywhere to match the current UI behavior.
- `Words` and `Recalls` are simulated numbers for visual realism only.
- `Status` is set to `Ready` for a clean recording baseline.

- Start with `Northwind Brand Hub` to show a dense table with many files and mixed formats.
- Then switch to `Northwind Store Ops` to show the system is not only for brand docs, but also for operational SOPs.
- Use one single-KB question first, then a cross-KB question to demonstrate retrieval across domains.
- If you want a cleaner screen, keep all document statuses as `Ready`.
- If you want to demonstrate filters, duplicate this checklist in your video editor and change 1-2 rows to `Processing` or `Failed`.
